# MyAI — AI Lab First Neuron

Interactive bilingual AI laboratory built with React, TypeScript and Vite. The experience guides a researcher through data, features and the first trainable neuron inside a phosphor-terminal interface.

## Run locally

```bash
npm install
npm run dev
```

## Verification

```bash
npm run type-check
npm test
npm run test:e2e
npm run build
```

The interface supports Russian and English and adapts to desktop and mobile screens.
